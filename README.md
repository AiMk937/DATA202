## 📖 About This Course

This repository contains all homework, and the team semester project for
**DATA 202** — the mathematical backbone behind data intelligence: statistics,
probability, calculus, and linear algebra, all tied back to real analytics workflows.



## 🧭 Topics Covered

| # | Topic | Key Concepts |
|---|-------|---------------|
| 1 | Intro to E2E Data Science | Full project lifecycle overview |
| 2 | Measurements & Sampling | Sampling theory & measurement scales |
| 3 | Variable Types | Statistical & graphical summaries |
| 4 | Correlation & Covariance | Data distribution theorems |
| 5 | Confidence Intervals | Estimation & interval construction |
| 6 | Hypothesis Testing | Significance, p-values, test design |
| 7 | Probability Events | Random variables |
| 8 | Probability Distributions | Common distributions & properties |
| 9 | Calculus & Optimization | Derivatives, gradients, optimization methods |
| 10 | Linear Algebra | Vectors, matrices, transformations |
| 11 | Systems of Linear Equations | Solving & applications |
| 12 | Math → Data Intelligence | Tying it all together |
